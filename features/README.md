# Features backlog

Planned features we want but are **not** building yet — one file per feature, so
intent and open questions aren't lost. This is a parking lot, not a schedule or a
commitment.

Near-term, sequenced work lives in [../docs/roadmap.md](../docs/roadmap.md);
this folder is the longer-horizon reference.

## Index

- [coach-marketplace.md](coach-marketplace.md) — coaches publish their own programs and earn commissions

## Adding a feature

Copy this template into `features/<kebab-name>.md`:

```md
# <Feature name>

**Status:** idea — not scheduled
**Added:** YYYY-MM-DD

## Summary
One or two sentences: what it is and who it's for.

## Why
The motivation / problem it solves.

## Open questions
Decisions to resolve before building.

## What it would touch
Data model, roles, billing, APIs, screens — so we keep it possible.

## Prerequisites
What should exist first.
```
